# AutoMirrorCore

Open-source Android Auto screen mirroring app with two-way touch injection.

## Features

- Screen mirroring via MediaProjection to Android Auto
- Touch injection via Accessibility Service or Shizuku
- Coordinate transformation between phone and car display
- Display resolution optimization for car screens

## Building

This project uses GitHub Actions to build APKs automatically. Download the latest build from the Actions tab.

## Requirements

- Android 10+ (API 29)
- Shizuku (optional, for enhanced touch injection)
- Accessibility Service enabled
